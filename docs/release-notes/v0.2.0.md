# GameTimeRecord v0.2.0

## 新功能

- 游玩记录按游玩次数分组，并以时间线展示开始、暂停、恢复和结束操作
- 每次游玩显示当前状态、开始时间和有效时长
- 每条操作记录可以直接修改时间

## 界面改进

- 游玩记录详情默认显示，不再需要手动展开整个区域
- 最近一次游玩默认展开，较早记录可以单独展开或收起
- 统一信息、错误、警告和删除确认窗口的视觉样式
- 优化状态、时间戳、操作节点和会话卡片的视觉层级
- 可选的游戏别名或平台未填写时不再显示多余分隔符

## 数据兼容

本版本沿用原有 SQLite 数据结构和数据目录，升级后可以直接读取已有游戏与游玩记录。
