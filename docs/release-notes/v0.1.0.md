# GameTimeRecord v0.1.0

首个公开版本。

## 功能

- 新建、编辑和删除游戏资料
- 同时记录多个游戏的游玩时间
- 支持开始、暂停、恢复和结束游玩
- 所有操作时间精确到秒，并按 Windows 当前时区显示
- 修改历史操作时间后自动重新计算统计结果
- 查看累计游玩秒数、游玩次数、首次游玩时间和最后游玩时间
- 单独复制四项统计值，便于粘贴到其他平台
- 使用 SQLite 在本地保存游戏资料和游玩记录

## 系统要求

- Windows 10 或更高版本
- x64 处理器

下载 `GameTimeRecord-win-x64.zip`，解压后运行 `GameTimeRecord.exe` 即可。
